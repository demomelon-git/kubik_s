Расширение для Firefox и Fennec: свой поиск, который одновременно берёт результаты из Google, Microsoft Bing и Brave и объединяет их.

Как поставить

  1. Скачай подписанный файл .xpi по кнопке выше.
  2. Fennec: «Настройки» → «О Fennec», 5 раз нажми на логотип.
  3. Выбери «Установить дополнение из файла» и укажи скачанный файл.
  4. Открой https://127.0.0.1/ — появится Кубик.

Эта страница не умеет искать сама: браузер запрещает обычным сайтам читать выдачу других поисковиков. Поиск работает только внутри расширения.
