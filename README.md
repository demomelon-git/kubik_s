# Кубик — поиск из Google, Bing и Brave

Расширение для Firefox и Fennec (Android) с собственной главной страницей, помощником Кубиком и поиском, который **одновременно** берёт результаты из трёх источников:

- Google
- Microsoft Bing
- Brave Search

Результаты объединяются: если сайт нашли несколько систем, он поднимается выше (метод reciprocal rank fusion), а рядом с ним видны значки источников. Если один источник не ответил, остальные всё равно показываются.

## Почему это расширение, а не просто сайт

GitHub Pages отдаёт только статические файлы, а браузер не даёт обычной странице читать чужие сайты (CORS). Поэтому сайт на GitHub не может сам собрать выдачу Google, Bing и Brave. Расширению браузер такие запросы разрешает, поэтому весь поиск работает в нём, а в `docs/` лежит страница-визитка с кнопкой скачивания.

## Структура

```
extension/   исходники расширения
docs/        страница для GitHub Pages
.github/     сборка и подпись расширения (GitHub Actions)
```

## Как установить

1. Нужен **подписанный** файл `.xpi` (Firefox и Fennec не ставят неподписанные).
2. Подпись делает GitHub Actions автоматически, см. ниже. Либо загрузи `extension/` (в виде zip) на addons.mozilla.org как неопубликованное расширение и скачай `.xpi`.
3. Fennec: «Настройки» → «О Fennec», 5 раз нажми на логотип → «Установить дополнение из файла».
4. Fennec: открой `https://127.0.0.1/` — откроется Кубик. Чтобы искать из адресной строки, добавь поисковую систему с адресом `moz-extension://<id>/results.html?q=%s` (id показывает Firefox в `about:debugging` или в настройках дополнения).

## Автоматическая подпись через GitHub Actions

1. На addons.mozilla.org: **Инструменты → Управление ключами API** — создай ключи.
2. В репозитории: **Settings → Secrets and variables → Actions** — добавь секреты `AMO_JWT_ISSUER` и `AMO_JWT_SECRET`.
3. Поменяй `version` в `extension/manifest.json` (AMO не принимает повторяющийся номер версии) и сделай push в `main`.
4. В разделе **Actions** скачай артефакт `kubik-signed` (внутри `.xpi`). Если создать тег вида `v2.0.1`, подписанный файл прикрепится к релизу.

## GitHub Pages

**Settings → Pages → Branch: main, папка `/docs`.** Страница сама найдёт ссылку на последний релиз.

## Помощник Кубик (необязательно)

Нажми на Кубика, затем ⚙ и вставь свой API-ключ Gemini. Ключ хранится только в браузере (`storage.local`) и в репозиторий не попадает.

## Ограничения

- Google отдаёт результаты через скрытый фрейм, поэтому он медленнее остальных (до 15 секунд) и может показать капчу или окно согласия, тогда два других источника продолжат работать.
- Разметка страниц Google, Bing и Brave может измениться, и разбор придётся поправить в `extension/content.js` и `extension/engines.js`.
- На Android нельзя подменить кнопку «новая вкладка», поэтому используется адрес `https://127.0.0.1/`.
- Проект личный и не связан с Google, Microsoft или Brave. Используй его для собственного поиска и соблюдай правила этих сервисов.
